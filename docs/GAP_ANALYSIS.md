## สรุปผู้บริหาร

ระบบปัจจุบันเป็น **บทเรียนหน้าเดียว 8 Section พร้อมระบบบัญชีและบันทึกความก้าวหน้าที่แข็งแรง**
จุดแข็งอยู่ที่ความปลอดภัย การตรวจสอบฝั่งเซิร์ฟเวอร์ และการเรียกคืนงานอัตโนมัติ
ซึ่งทำได้ดีกว่าที่คาดสำหรับระบบขนาดนี้

**รอบที่ 2 ปิดช่องว่างด้านการนำทางแล้ว** ซึ่งเป็นหมวดที่ Blueprint และ CLAUDE.md
ให้น้ำหนักมากที่สุด ตอนนี้นักเรียนย้อนกลับไปทบทวนได้เสมอ แต่ข้าม Required Step
ไปข้างหน้าไม่ได้ และการบังคับอยู่ที่เซิร์ฟเวอร์ ไม่ใช่แค่ซ่อนใน UI

**ช่องว่างใหญ่ที่สุดที่เหลือคือ ระบบแรงจูงใจทั้งหมด** (XP, Badge, Level, Streak,
Celebration) ซึ่งยังไม่มีเลยแม้แต่ส่วนเดียว ทั้งที่ Blueprint ให้พื้นที่ถึง 19 หัวข้อ

## ข้อเสนอลำดับความสำคัญ

จัดตามผลกระทบต่อการเรียนรู้จริง หารด้วยความพยายามที่ต้องใช้

### ระดับ 1 — ✅ ทำเสร็จแล้วในรอบที่ 2

1. ~~**Navigation Lock Engine** (#10–#16)~~ — เสร็จแล้ว
   บังคับลำดับที่เซิร์ฟเวอร์ด้วย `contiguousCompleted_()` และ `unlockedSection_()`
   ปิดช่องโหว่ที่เดิมข้ามได้ด้วยการเรียก `recordQuizAttempt` ตรง

2. ~~**Next Required Step + แถบความก้าวหน้า** (#12, #60)~~ — เสร็จแล้ว
   แถบติดด้านบนบอกขั้นถัดไปพร้อมปุ่มพาไป และแถบความก้าวหน้าใน header
   ที่เดิมค้างอยู่ที่ "Section 8 / 8" ตายตัว ตอนนี้ทำงานจริงแล้ว

3. ~~**Student Detail รายข้อสำหรับครู** (#77)~~ — เสร็จแล้ว
   ครูเห็นได้ทันทีว่านักเรียนพลาดข้อไหนและเลือกตัวเลือกใด

### ระดับ 2 — เพิ่มคุณภาพการเรียนรู้ชัดเจน

4. **ระบบ XP และ Badge ขั้นพื้นฐาน** (#56, #63, #64)
   เริ่มจาก XP ต่อกิจกรรม + Badge จบบท + Personal Best ก็เห็นผลแล้ว

5. **Hint System 2 ระดับ** (#45)
   Hint 1 → Hint 2 → ตัวอย่าง ตามที่ Blueprint กำหนด

6. **Item Analysis สำหรับครู** (#76, #196)
   สรุปว่าข้อไหนทั้งห้องตอบผิดเยอะ พร้อมข้อเสนอว่าควรสอนซ้ำเรื่องใด

7. **หน้าจอสะท้อนผล** (#53, #100)
   แผนการสอนกำหนดไว้ชัดในคาบที่ 2 นาที 56–60 แต่เว็บยังไม่มีให้กรอก
   ต้นทุนต่ำเพราะ backend รับค่า `reflection` ไว้แล้ว เหลือแค่ทำหน้าจอ

### ระดับ 3 — ลงทุนระยะยาว

8. **Data-driven Lesson + Reusable Components** (#85, #86)
   จำเป็นถ้าจะมีบทที่ 2 ขึ้นไป ตอนนี้เพิ่มบทใหม่ต้องเขียนโค้ดใหม่ทั้งหมด

9. **Teacher Preview Mode แบบ Synthetic Session** (#78, #113)
   แม้ยุบ role ครูเข้ากับ admin แล้ว ข้อนี้ก็ยังจำเป็น

10. **Mini Game และ Mission ที่แท้จริง** (#40, #42)

11. **Network Recovery และ Sync Conflict** (#102, #195)
